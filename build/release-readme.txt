NetPulse {version}

Windows 11(x64)에서 간헐적인 네트워크 끊김을 기록하고 진단하는 앱입니다.

실행
- 설치하지 않습니다. NetPulse.exe를 원하는 폴더에 두고 실행하세요.
- 처음 실행할 때 사용 조건(TERMS.txt)에 동의해야 합니다.
- 코드 서명이 없어 Windows SmartScreen 경고가 나올 수 있습니다. [추가 정보] → [실행]으로 열 수 있습니다.
- 관리자 권한이 필요 없고, 네트워크 설정을 바꾸지 않습니다.

기록과 설정
- 기록·설정은 %LOCALAPPDATA%\NetPulse 아래에 저장됩니다. 기록 저장 위치는 설정에서 바꿀 수 있습니다.
- 기록은 이 PC에만 남습니다. 리포트를 내보낼 때만 파일로 만들어지고, 기본으로 주소 같은 식별 정보를 가립니다.

지우기
- NetPulse.exe를 지우고, 필요하면 %LOCALAPPDATA%\NetPulse 폴더도 지우세요.

라이선스
- NetPulse는 MIT 라이선스입니다(LICENSE.txt).
- 함께 들어 있는 구성요소의 조건은 THIRD-PARTY-NOTICES.txt에 있습니다. 다시 배포할 때는 TERMS.txt, LICENSE.txt, THIRD-PARTY-NOTICES.txt를 함께 전해야 합니다.
