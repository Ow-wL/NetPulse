# M0 디자인 시안 (D2)

- 파일: `spikes/design/home-mockups.html` (브라우저로 열면 움직인다. 아래 막대로 시안, 테마, 끊김 연출을 바꾼다)
- 캡처: `docs/loop/m0/design/` (1440×900, 합성 데이터)
- 세 시안은 **같은 홈 화면, 같은 배치, 같은 데이터**다. 다른 것은 색, 빛, 유리의 성격이다. 배치와 기능은 기획서 7.5절을 따른다.

## 공통 화면 구성

| 영역 | 내용 | 가져온 곳 |
| --- | --- | --- |
| 등급 링과 결론 | 연결 품질 등급(A~D)과 점수, 한 문장 결론, 근거 한 줄 | 품질 등급과 쉬운 설명: EMCO Ping Monitor의 4단계 품질, PeakHour의 문자 등급 (N2) |
| 측정 시작 | 가장 큰 행동 버튼, 옆에 빠른 진단 | 첫 실행 안내 (N14) |
| 연결 경로 | 이 PC → 공유기 → 인터넷을 노드와 흐르는 빛으로. "개념도" 표시 | Claude 제안 (N13). 실제 경로가 아님을 밝히라는 Codex 지적 반영 |
| 최근 2분 | 지연선, 응답 없음 세로 띠, 증상 표시 마커를 한 축에. 지연(ms)과 시간 축 표시 | 겹침 타임라인: PingPlotter의 타임라인 그래프 (N1) |
| 최근 측정 | 측정마다 등급, 길이, 연결 방식, 메모, 끊김 횟수와 최장 길이 | 끊김 목록과 통계: Net Uptime Monitor, EMCO (N3, N8) |
| 빠른 진단 요약 | 여섯 검사의 상태 칩과 검사 시각 | 기존 앱의 빠른 진단 (F1), Apple 무선 진단의 요약 화면 (N5) |
| 상주 표시 | 백그라운드 모니터링 상태 | 트레이 상주: Net Uptime Monitor, iStat Menus (N7) |

**공통 연출**: 카드가 차례로 떠오름, 등급 점수가 올라감, 경로에 빛이 흐름, 타임라인이 매초 밀려 들어옴, 로고의 심박선, 측정 시작 버튼의 광택이 지나감, 포인터를 따라가는 빛, 테마 전환 시 원형 확산.

**끊김 연출** (막대의 "끊김 연출"): 배경 빛이 붉게 물들고, 경로의 공유기→인터넷 구간이 붉게 깜빡이며, 등급이 D로 내려가고, 빠른 진단의 인터넷·HTTPS 칩이 실패로 바뀐다. 결론은 "외부 인터넷 연결이 끊긴 것으로 보입니다"다. 기획서 6.2의 판정 구분 중 "외부 연결 단절 추정"이므로 단정하지 않는다. 근거 한 줄에 "공유기는 응답하지만 서로 다른 외부 대상 3곳이 함께 응답하지 않습니다"를 쓴다.

## 세 시안

### 오로라 (`aurora-*.png`)
- 깊은 남색 위로 청록·보라·파랑 빛이 천천히 흐르고, 비스듬한 오로라 띠가 지나간다.
- 유리에 배경색이 번지고, 강조색(청록→보라 그라디언트)이 네온처럼 빛난다. 제목과 등급에 그라디언트 글자.
- 가장 화려하다. 라이트는 민트·라벤더 빛에 흰 서리 유리.

### 흑요석 (`obsidian-*.png`)
- 거의 검은 바탕에 아주 옅은 남색 빛, 미세한 결.
- 유리가 얇고 날카롭다(블러 약함, 1px 선명한 테두리). 강조색은 하늘색 하나, 빛 번짐 없음.
- 절제된 고급스러움. 라이트는 백자 같은 회백색.

### 프리즘 (`prism-*.png`)
- 남보라 바탕에 남색·분홍·청록·호박 빛.
- 모든 유리 가장자리를 무지갯빛 테두리가 천천히 돈다. 강조색은 분홍→청록.
- 상태 변화에 가장 크게 반응한다. 라이트는 흰 바탕에 무지갯빛 테두리.

## 시안 비교

아래는 Claude의 눈으로 본 평가다. 대비를 계산하지 않았으므로 "읽기"는 정량 검증이 아니다.

| | 오로라 | 흑요석 | 프리즘 |
| --- | --- | --- | --- |
| 화려함 | 가장 높음 | 낮음 (의도적) | 높음 |
| 숫자·그래프 읽기 (눈으로 본 인상) | 밝은 청록 배경 위 보조 글자는 조정 필요 | 가장 차분함. 단, 두 그래프와 범례가 같은 강조색이라 구분이 약함 | 무지갯빛 테두리가 모든 카드와 칩에 있어 중요도 차이가 약해짐 |
| 오래 켜 둘 때 피로 | 중간 | 낮음 | 높음 (테두리가 계속 돎) |
| C(WinUI)로 옮길 때 품 | 중간 (흐르는 빛, 그라디언트 글자) | 낮음 | 높음 (회전하는 무지갯빛 테두리) |

세 시안은 재질과 빛의 방향이 다를 뿐 화면 구조는 같다. 기획서가 같은 홈 화면으로 비교하라고 했기 때문이다. 화면 구조(배치, 탐색)는 M5 설계에서 다시 검토한다.

**고를 때 섞을 수 있는 것** (예): 오로라의 빛과 색 + 흑요석의 얇고 날카로운 유리, 또는 오로라 + 프리즘의 무지갯빛 테두리를 측정 시작 버튼과 끊김 상태에만.

## 알려진 한계

- 합성 데이터다. 실제 측정값의 범위와 다를 수 있다.
- 홈 화면 하나만 만들었다. 측정, 기록, 리포트 화면은 고른 시안을 기준으로 M2·M5 이후에 만든다.
- 대비를 계산으로 검증하지 않았다. 가장 불리한 배경 조건의 대비 검사는 M2에서 디자인 토큰을 확정한 뒤 한다.
- 고대비 모드의 대체 화면은 시안에 없다. 효과 줄이기(`aurora-dark-reduced.png`)만 있다. 고대비는 M2에서 만든다.
- "잘 팔리는 디자인"은 입증하지 못했다. 조사한 제품들이 공통으로 내세우는 기능과 화면 구성을 참고했고, 색과 빛은 사용자가 말한 애플 글래스모피즘 취향에 맞춰 Claude가 제안했다.
