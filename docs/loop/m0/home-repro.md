# 흑요석 홈 시안의 WinUI 3 재현 (D1 확정 전 확인)

- 목적: 사용자가 C(WinUI 3)를 조건부로 고르면서, 고른 흑요석 시안을 C로 같은 품질로 낼 수 있는지 확인한다 (`DECISIONS.md` "D1 조건부 선호").
- 소스: `spikes/c-winui/HomeWindow.cs` (`NetPulseSpikeC.exe --home`). 시안: `spikes/design/home-mockups.html`.
- 캡처: `spikes/tools/capture-home.ps1`. C는 창의 클라이언트 영역 1440×900, 시안은 같은 크기의 Edge 헤드리스.
- 비교 이미지: `home-repro/compare-*.png` (왼쪽 시안, 오른쪽 C), `home-repro/compare-transition.png` (테마 전환 네 시점)

## 만들면서 바뀐 것

- 원형 확산을 처음에는 화면을 비트맵으로 찍어 겹치는 방식으로 했다. 배경 빛이 화면 밖까지 넘치게 그려져 비트맵이 화면보다 크게 찍혔고(2278×1933) 위치가 어긋났다. 비트맵 없이 살아 있는 두 장면을 겹치는 방식으로 바꿨고, 시작 지연도 약 220 ms에서 37 ms로 줄었다.
- 한국어 제목이 단어 중간에서 줄바꿈됐다. 단어 단위 줄바꿈(`WrapWholeWords`)으로 고쳤다.
- 타이머를 지역 변수로 두면 가비지 수집되어 멈출 수 있어 필드로 붙잡았다 (자동 종료가 안 되던 원인으로 추정).

## 남은 차이와 확인하지 못한 것

- 연한 오로라 세기 (위).
- 흑요석 시안의 미세한 결(점 무늬 질감)은 옮기지 않았다.
- 타임라인 두 그래프가 같은 색인 것은 시안 그대로다. M2에서 보조 계열색을 정한다 (`DECISIONS.md` D2).
- 이 화면의 프레임·자원은 재지 않았다. 스파이크 시험 장면(P2·P3)은 통과했지만 이 화면은 요소가 더 많다. M2·M5의 G5 프레임 기준으로 잰다.
- 다른 배율, 고대비, 키보드 초점은 확인하지 않았다.
