- 화면에서 볼 것: 프로필 셋째 줄 높이(포트 칸 없음일 때 위 붙임), 기록 목록 150% 첫 줄이 두 줄이 될 때 칩과의 세로 정렬, 고지 펼침 스크롤 위치와 bench 프레임, 리포트 안내가 위에 생길 때 옵션 카드가 밀리는 모습.
- 결론 문장 횟수 변경은 앱의 홈·기록 목록·측정 결과 문장에도 같이 적용된다(같은 `Sentences.For`). 판정이 바뀌는 끊김이 없는 기록은 숫자가 같다.
