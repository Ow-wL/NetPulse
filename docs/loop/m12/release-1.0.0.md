# 1.0.0 릴리스 본문 초안

게시는 사용자 승인 뒤. 아래 `<…>` 칸은 노트북 최종 게이트·증거 검토 뒤 채운다. 0.9.0 본문과 같은 꼴이다.

---

NetPulse 1.0.0
Windows 11에서 간헐적인 네트워크 끊김을 기록하고, 어디서 끊겼는지 근거를 모아 보여 주는 앱의 첫 정식 버전입니다.

## 받기

| 파일 | 내용 |
| --- | --- |
| `NetPulse-1.0.0-win-x64.zip` | `NetPulse.exe`, `LICENSE.txt`, `TERMS.txt`, `THIRD-PARTY-NOTICES.txt`, `읽어보기.txt` |
| `NetPulse-1.0.0-win-x64.exe` | zip 안과 같은 exe 하나 |
| `SHA256SUMS.txt` | 위 두 파일의 SHA-256 |
| `release.json` | 버전, 원본 커밋, 파일 해시 |

- 설치하지 않습니다. 원하는 폴더에서 실행하면 됩니다. Windows 11 (x64), 다른 런타임을 따로 설치할 필요가 없습니다.
- 처음 실행할 때 사용 조건에 동의해야 합니다. NetPulse 자체는 MIT이고, 함께 들어 있는 구성요소(Windows App SDK, .NET 런타임 등)의 조건이 함께 적용됩니다. 원문은 앱의 설정 → 정보 → 라이선스와 고지, 또는 zip 안의 파일에서 볼 수 있습니다.
- 코드 서명이 없어 Windows SmartScreen 경고가 나올 수 있습니다. [추가 정보] → [실행]으로 열 수 있습니다.

## 0.9.0에서 바뀐 것

- **Wi‑Fi 신호**: 무선으로 연결돼 있으면 신호 품질을 함께 기록해 타임라인과 리포트에 겹쳐 보여 줍니다. 위치 권한이 필요 없는 정보만 읽고, 네트워크 이름(SSID)은 기록하지 않습니다. 끊김 판정에는 쓰지 않고 관측으로만 보여 줍니다.
- **측정이 끝난 타임라인**: 측정이 끝나는 순간 그래프 선이 빠져 보이던 문제를 고쳤습니다.
- **쉬운 말**: 화면·리포트의 용어를 맞췄습니다 (예: "손실률" → "응답 없음 비율", "구간 후보" → "가능성이 높은 곳", 게이트웨이는 "공유기(게이트웨이)"). 오류 안내에 내부 코드 대신 사유를 적습니다.
- **보기**: 배경에 미세한 결을 넣었고(투명 효과를 쓸 때만), 투명 효과를 끈 화면의 색을 다시 정했습니다. 비활성 단추는 흐리게 하는 대신 읽을 수 있는 색과 점선 테두리로 보여 줍니다.
- **표시 결함**: 경로 맵 선 끝, 포트 입력 칸 폭, 리포트 내보내기 안내 위치 등을 고쳤습니다.
- **시작 기록**: 앱이 시작 단계 이름과 시각을 `%LOCALAPPDATA%\NetPulse\startup-trace.jsonl`에 남깁니다 (아래 알려진 문제).

## 주요 기능

- **측정**: 공유기·외부 대상 여러 곳에 1초마다 Ping(또는 TCP 포트)을 보내 응답 없음과 지연을 겹친 타임라인으로 보여 줍니다.
- **끊김 판정**: 끊김마다 어느 구간을 먼저 확인할지 관측한 근거와 함께 보여 줍니다.
- **빠른 진단**: 어댑터, 공유기(게이트웨이), 외부 연결, DNS, HTTPS, 네트워크 로그인, 링크 상태를 단계별로 확인합니다.
- **기록과 리포트**: 지난 측정을 다시 열고 비교하며, 통신사에 보낼 HTML 리포트를 만듭니다(기본으로 식별 정보를 가림).
- **상주**: 측정 중에 창을 닫으면 트레이에서 계속 재고, 끊기면 풍선 알림으로 알려 줍니다.

자세한 내용은 [README](https://github.com/Ow-wL/NetPulse#readme)를 보세요.

## 알려진 문제

- 일부 금융 보안 프로그램(예: RaonSecure TouchEn nxWeb)이 설치된 PC에서 NetPulse가 시작 직후 꺼진 일이 있습니다(예외 코드 0xc0000005). 그 PC에서는 여러 금융 보안 프로그램을 함께 지우고 재부팅한 뒤 정상 실행을 확인했습니다. 다시 재현하지 못해 원인은 아직 확인하지 못했습니다. 같은 일이 생기면 이슈로 알려 주시고, `%LOCALAPPDATA%\NetPulse\startup-trace.jsonl`(단계 이름과 시각만)을 함께 보내 주세요.
