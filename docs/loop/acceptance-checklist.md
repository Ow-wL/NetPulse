# NetPulse 인수 체크리스트

M11 설계 F (`docs/loop/M11-design.md`). 기획서 1절 "제품 출시" 7: 루프가 끝난 뒤 사용자가 확인하는 항목이다. 자동 시험·데모 캡처·이 PC 한 대의 실측으로 대신할 수 없는 것만 넣었다.

- 대상 파일: M11 최종 게이트를 통과한 배포 파일 (`M11-completion.md` "검증한 배포 파일"의 SHA-256과 같은 파일). 0.9.0 게시본으로 확인해도 되지만, 그때는 어느 파일로 했는지 적는다.
- 기록: 항목마다 날짜, 쓴 PC(유선·Wi‑Fi, 화면 주사율·배율 정도만, 이름·주소는 적지 않는다), 결과(통과 / 문제 / 못 함), 메모. 문제가 있으면 이슈나 다음 마일스톤으로 넘긴다.
- 이 문서는 공개 저장소에 있다. 실제 IP, MAC, 어댑터 이름, SSID, 컴퓨터 이름, 사용자 이름, 경로를 적지 않는다.

| 1 | **실제 단선** | 측정을 시작한 뒤 ① 랜선(또는 Wi‑Fi)을 30초 끊었다 다시 연결, ② 공유기 전원을 끄고 켬, ③ 공유기 WAN 선만 뽑았다 꽂기. 각각 끝나면 측정 중지 | 끊김 구간이 타임라인 띠·끊김 목록에 실제 시각대로 남는다. 구간 후보가 ①은 내 PC 쪽(링크 근거), ②는 공유기, ③은 공유기 밖으로 기운다. 창을 숨겨 두었다면 풍선이 한 번 뜬다. 단정하는 문구가 없다 | | | | |
| 2 | **장시간 측정** | 프로필의 측정 시간을 길게(예: 8시간 이상, 최대 720분) 잡고 창을 숨긴 채 둔다. 끝나면 다시 연다 | 측정이 끝까지 이어지고 기록이 봉인된다(기록 화면에 "계획한 시간을 마침"). 메모리 사용이 크게 늘지 않는다(작업 관리자에서 대략 500 MB 아래). 다시 열 때 화면이 끊김 없이 그려진다. 닫을 때 비정상 종료가 없다 | | | | |
| 3 | **화면 품질** | 홈 → 측정 → 진단 → 기록 → 리포트 → 설정을 직접 써 본다 (다크·라이트 둘 다) | 체감 지연·깜빡임·글자 흐림이 없다. 유리 재질과 배경 빛이 산만하지 않다. 결론이 먼저 보인다 | | | | |
| 4 | **실제 접근성 설정** | Windows 설정에서 ① 고대비 테마(Aquatic, Desert), ② 투명 효과 끄기, ③ 애니메이션 효과 끄기, ④ 디스플레이 배율 150%를 각각 켜고 앱을 본다. 앱이 켜져 있는 동안 바꿔도 본다 | 시험은 시뮬레이션이었다. 실제 설정에서도 글자가 읽히고, 초점 테두리가 보이고, 잘림이 없다. 움직임이 멈춘다. 제목 표시줄이 테마와 맞는다 | | | | |
| 5 | **깨끗한 Windows 11** | 개발 도구가 없는 PC나 가상 머신에서 Release의 zip을 풀거나 exe 하나만 받아 실행 → 사용 조건 동의 → 첫 측정 | 추가 런타임 설치 없이 실행된다. 동의 후 세 단계 안에 측정이 시작된다 | | | | |
| 6 | **SmartScreen** | 받은 exe를 처음 실행 | 경고가 나오면 [추가 정보] → [실행]으로 열린다 (README와 같다) | | | | |
| 7 | **트레이와 풍선** | 측정 중 창을 닫는다 → 작업 표시줄 알림 영역의 아이콘 확인 → 아이콘 클릭으로 다시 열기 → 아이콘 오른쪽 클릭 메뉴에서 [증상 표시], [종료]를 마우스로 누른다 | 아이콘이 밝은·어두운 작업 표시줄에서 보인다. 다시 열면 같은 측정이 이어진다. [종료]는 저장 후 끝낸다 (자동 시험에서는 메뉴 [종료]를 UIA로 고르는 것이 무시돼 마우스 확인이 필요하다) | | | | |
| 8 | **Wi‑Fi 링크 근거** | Wi‑Fi로 연결된 PC(노트북)에서 측정 중 Wi‑Fi를 껐다 켠다 | 링크 근거에 무선 연결 끊김·복구가 그 시각에 남고 구간 후보가 내 PC 쪽으로 기운다. Wi‑Fi 로그를 읽을 수 없는 PC라면 "근거 없음"이 정직하게 표시된다 (R2 Wi‑Fi는 자동 시험이 해석까지만 본다) | | | | |
| 9 | **통신사 제출용 리포트** | 끊김이 있는 실제 측정으로 리포트를 "통신사에 보낼 때(가리기)"로 내보내 브라우저로 열고, 인쇄 미리 보기(A4)도 본다 | 주소·어댑터 이름 같은 식별 정보가 가려져 있다. 그래도 끊김 시각·구간 후보·근거가 통신사에 설명이 된다. 인쇄 배치가 깨지지 않는다 | | | | |
| 10 | **법률 판단** | `TERMS.txt`, 첫 실행 동의 화면, `THIRD-PARTY-NOTICES.txt`를 읽는다 | 첫 실행 동의와 원문 제공이 Windows App SDK 라이선스 3(b)(ii)의 요구를 충족한다고 판단하는지, 3(b)(iii)(배포자 면책 의무)를 받아들이는지 사용자가 정한다. 루프는 법률 판단을 하지 않았다 | | | | |
| 11 | **알려진 문제 안내** | README와 Release 본문의 "알려진 문제"를 읽는다. 금융 보안 프로그램이 있는 PC가 있으면 실행해 본다 | 안내가 실제 증상과 맞다. 고치는 일은 M12(1.0.0 조건) | | | | |
| 12 | **닫을 때 비정상 종료 관찰** | 1~9를 하는 동안 앱을 닫을 때마다 오류 창이나 갑작스런 종료가 있었는지 본다 | 없다. 있으면 날짜와 상황을 적는다 (드문 0xC000027B, `CardBody.Set` 접근 위반은 재현 없이 계측만 하고 있다) | | | | |
